## 一、数据级问题(最先修)

**A1. 中文名源的 id 全塌成 `-`**

`normSource()` 用名字生成 id:`name.toLowerCase().replace(/[^a-z0-9_-]+/gi,'-')`,中文全部被替换,`slice(0,24)` 后就是 `-`。

现状已经踩到:

```
libvio-1 = libvio
-3 = 独播库
-5 = 厂长资源
-7 = 欧乐影视
-8 = 无水印资源
```

现在没撞车纯属运气。一旦重复:点 A 行切到 B 源、删一个删两个。

改法:id 与名字解耦,用短哈希或随机串;启动时发现重复 id 重排并落盘;删除按对象而非 id。

- 播放中点侧栏,背面换视图
- 自动判型后下拉锁死,用户改不了
- 滚动条全隐藏,长列表无"还有内容"暗示
- 收藏进详情静默切源

### 交互缺口

1. 播放器没有选集面板:跳到第 8 集要退出→回详情→选集→重新起播
2. 播放中不能换源
3. 源不能停用(规格里有"已停用"样式,实现没有状态)
4. 没有导出/备份
5. 首页正常列表没有刷新入口
6. 没有清空数据入口
